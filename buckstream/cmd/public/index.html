BuckStream is a storage broker that proxies uploads, streams downloads, and hosts static sites — all from your private S3, GCS, R2, or B2 bucket. No public ACLs. No vendor lock-in. One 10 MB binary.

Features
Everything you need,
nothing you don't.

Private by default

Your storage bucket never needs to be public. The broker is the only entity with storage credentials.

Wildcard subdomains

Every deployed site gets its own subdomain automatically. site.yourdomain.com — zero DNS config per site.

RAM-speed serving

ZIPs are unzipped into memory on first load. Every subsequent request is served in under 1 millisecond.

Zero-downtime updates

Deployments hot-swap the in-memory cache using Go's RWMutex. Old site stays live until the new one is ready.

Multi-cloud storage

Works with AWS S3, Google Cloud Storage, Cloudflare R2, Backblaze B2, and any S3-compatible provider.

Keyless IAM auth

On AWS or GCP, use IAM roles and Application Default Credentials. No static secrets stored anywhere.

Storage Broker
Smart upload & download routing.

BuckStream intelligently routes uploads and downloads — small files stream through the broker, large files go direct. Your bucket stays private either way.

Upload
POST /api/upload*
≤ 5 MB
POST /api/upload/proxy
File streams directly to the broker, which writes it into the private bucket. Auth token verified on every request.
> 5 MB
POST /api/upload-intent → Pre-signed PUT URL
Client requests a signed URL from the broker. File is uploaded directly to S3/GCS — zero bandwidth on the broker.
Object Operations
GET · DELETE /api/*
Download
GET /api/download/:key
File is streamed from the private bucket through the broker to the client. Content-Type and ETag headers set automatically.
Bucket → Broker → Client
List
GET /api/list
Returns all object keys under the uploads/ prefix. Auth token required.
Delete
DELETE /api/delete?key=uploads/file
Permanently removes the object from the bucket and frees memory cache. Auth token required.
Deploy
POST · GET · DELETE /api/deploy*
Deploy
POST /api/deploy
Upload a ZIP archive to deploy a static site. Unzipped into RAM and served instantly at its subdomain.
ZIP → RAM cache → site.yourdomain.com
List
GET /api/deploy/list
Returns all deployed site names. Auth token required.
Delete
DELETE /api/deploy/delete?name=site
Removes site ZIP from the bucket and evicts it from the RAM cache immediately. Auth token required.

Client SDKs
One install. Four methods.

Available for Node.js / browser (JS & TS) and Python. Full TypeScript types included.

JavaScript & TypeScript
npm
npm install buckstream-client 
import { BuckStreamClient } from 'buckstream-client';
const client = new BuckStreamClient('https://broker.yourdomain.com', 'your-token');

await client.Upload(file, 'photo.jpg', 'image/jpeg');
await client.List();
await client.Download('uploads/photo.jpg');
await client.Delete('uploads/photo.jpg');
Python
pip
pip install buckstream-client 
from buckstream import BuckStreamClient
client = BuckStreamClient('https://broker.yourdomain.com', 'your-token')

client.Upload('photo.jpg', 'uploads/photo.jpg', 'image/jpeg')
client.List()
client.Download('uploads/photo.jpg')
client.Delete('uploads/photo.jpg')
