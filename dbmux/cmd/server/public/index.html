⚡ Key Architectural Mechanics
  • Single Socket Multiplexing: All RPC traffic flows over one HTTP/2 connection.
  • Isolated Connection Pools: Dedicated driver connection pool per DB type.
  • Per-Query Goroutines: Every incoming query spawns an independent Go worker.
  • Row Level Security (RLS): Native Postgres RLS + Gateway filter injection for Mongo & Redis.
