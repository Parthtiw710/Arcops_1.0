# 🤝 Contributing to ArcOps

Thank you for your interest in contributing to **ArcOps**! We welcome bug fixes, documentation improvements, and feature enhancements across all core microservices.

---

## 📋 Contribution Guidelines

Please follow these 3 simple steps when contributing:

1. **Read the Documentation First**:
   Before submitting changes or proposing features, please read the central [README.md](README.md) and the specific microservice README for the module you are working on:
   - ⚡ [frontedge/README.md](frontedge/README.md) — Universal Deployment Engine
   - 🔐 [arcauth/README.md](arcauth/README.md) — Identity & Authentication Engine
   - 🗄️ [dbmux/README.md](dbmux/README.md) — Multi-Database Multiplexer Proxy
   - 📦 [buckstream/README.md](buckstream/README.md) — S3 Object Storage Engine
   - 🌐 [gateway/README.md](gateway/README.md) — API Gateway Reverse Proxy
   - 🎨 [web/README.md](web/README.md) — Unified Web Console

2. **Open a GitHub Issue**:
   - Open an issue on GitHub describing the bug, feature request, or architectural enhancement.
   - Provide context and clear reproduction steps where applicable.

3. **Email a Brief Summary**:
   - After opening an issue then Pull Request, send a brief summary email to **Prasoon Sharma** at:
     ✉️ **`parthtiw710@gmail.com`**
   - Include your GitHub issue/PR link and a short summary of your proposed changes.
